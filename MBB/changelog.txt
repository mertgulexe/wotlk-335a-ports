Version 2.0.0
-------------
- Final release of MBB Reborn 2.0 after cross-client Alpha and Beta testing.
- Successfully tested on Retail, WoW Forever Beta, Classic Era, TBC Anniversary and Mists of Pandaria Classic.
- Added explicit WoW Forever interface support (16001).
- Added the Button Manager with enable/exclude controls, rescan and persistent custom ordering.
- Added drag-and-drop ordering plus Up/Down controls and Reset Order.
- Added account-wide profiles with create, activate, rename, duplicate and delete tools.
- Added quick profile switching directly from the main MBB settings.
- Profiles store layout, scale, detached-button position, positioning options and custom button order.
- Character-specific excluded buttons remain outside profiles.
- Added lockable detached-button positioning and optional snapping to WoW window edges.
- Added a clear multi-monitor limitation note: WoW addons cannot detect physical monitor boundaries.
- Made the MBB settings window movable and persist its position account-wide.
- Improved Button Manager presentation, status indication and frame layering.
- Preserved stable v1.x settings through automatic migration into the Default profile.
- Stable version communication is active again for 2.0.0, allowing older stable MBB clients to detect the new release.
- Fixed older-client XML compatibility on TBC Anniversary.
- Updated README and localization coverage for the 2.0 feature set.

# MinimapButtonBag Reborn v1.0.6

## 🇬🇧 English

### ✨ New
- Added configurable **button scaling from 75% to 150%**.
- General MBB settings are now stored **account-wide**.
- The exclude list remains **character-specific**.
- Added an **in-game version check** using the WoW addon communication channel.
- Added localized update notifications when a newer MBB version is detected.

### 🔧 Fixed
- Fixed **middle mouse button support** for collected minimap buttons.
- Addons can now correctly receive middle-click actions.
- Fixed button visibility after an addon hides or disables its own minimap button.
- Improved Show/Hide handling for collected minimap buttons.
- Fixed `/mbb reset all` so account-wide settings are reset correctly.
- Fixed patch/interface detection for the unified multi-version TOC.

### 🎨 UI
- Improved the wording of the secondary row direction option.
- Button scaling now applies cleanly to the MBB button and collected addon buttons.

### 🌍 Localization
- Updated all supported localization files.
- Added translations for button scaling.
- Added translations for update notifications.
- Updated the wording of the secondary row direction setting.
- All localization files are synchronized again.

- WoW Classic Era
- The Burning Crusade Classic
- Mists of Pandaria Classic
